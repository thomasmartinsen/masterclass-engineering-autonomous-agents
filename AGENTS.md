# Rules for AI agents in this masterclass

Participants solve the exercises in this repository themselves.

- Do not look at the `session-*` branches. They hold the reference solutions for participants who fall behind.
- If the participant asks for a reference solution, tell them to run `git switch session-N` themselves, as described in the exercise.
- Do not use the files in `exercises/` as context: they describe what the participant is meant to work out. Read them only when the participant asks you to directly.
